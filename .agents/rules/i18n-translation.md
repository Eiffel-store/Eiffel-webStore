# قاعدة الترجمة والنصوص المترجمة (i18n Translation Rule)

## 1. 🚫 الحظر التام والنهائي لاستخدام `isRTL` في اللغة أو الترجمة
- **ممنوع قطيعاً وبشكل صارم** استخدام المتغير `isRTL` في أي شرط لتبديل اللغة أو اختيار النصوص:
  ```tsx
  // ❌ ممنوع منعاً باتاً:
  {isRTL ? 'المنتجات' : 'Products'}
  placeholder={isRTL ? 'ابحث...' : 'Search...'}
  const title = isRTL ? item.nameAr : item.nameEn;
  if (isRTL) return item.name;
  ```

## 2. ✅ الإلزام التام باستخدام قاموس الترجمة المركزي `t`
- **يجب دائماً وبلا استثناء** استدعاء الترجمات عبر دالة/كائن `t` المستخرج من `useLanguage()`:
  ```tsx
  // ✅ الطريقة الوحيدة المعتمدة:
  const { t } = useLanguage();
  
  <span>{t.products}</span>
  placeholder={t.searchPlaceholder}
  ```
- لأي نص جديد، يتم إضافته أولاً في ملفات الترجمة:
  1. `src/i18n/types.ts`
  2. `src/i18n/locales/ar.ts`
  3. `src/i18n/locales/en.ts`

## 3. 🎯 البيانات الديناميكية القادمة من السيرفر (قواعد البيانات)
- إذا كان الكائن قادماً من الـ API ويحتوي على حقول ثنائية اللغة (مثل `name` و `nameEn` أو `titleAr` و `titleEn`):
  - يتم التحقق من كود اللغة الحالي عبر `language === 'ar'` فقط وليس `isRTL`.
  - أو استخدام دوال المساعدة المخصصة للترجمة.

## 4. 📐 الحالات الوحيدة المسموح فيها بـ `isRTL` (الاتجاه والمظهر فقط)
يقتصر استخدام `isRTL` حصراً على اتجاهات الواجهة البصرية (Visual Layout & Styling):
- اتجاه الصفحة والعناصر: `dir={isRTL ? 'rtl' : 'ltr'}`
- كلاسات التموضع: `isRTL ? 'right-4' : 'left-4'`
- دوران الأسهم والأيقونات الاتجاهية: `isRTL ? 'rotate-180' : ''`
- وسيط اللغات للتواريخ الزمنية: `toLocaleDateString(isRTL ? 'ar-EG' : 'en-US')`
